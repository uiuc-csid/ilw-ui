# C1: Modal on native `<dialog>`

_Phase 2 of [the toolkit-replacement plan](2026-10-20-toolkit-replacement.md) (tracking: [uiuc-csid/ilw-ui#9](https://github.com/uiuc-csid/ilw-ui/issues/9)). Replaces the `<ilw-modal>` wrapper; after this, `Modal`, `openModal`, `alert` and `confirm` need neither `toolkit.js` nor `toolkit.css`._

## Sources read

`web-illinois/ilw-modal` v1.2.1: `src/ilw-modal.ts`, `src/ilw-modal.styles.css`, `src/ilw-modal.css`. What it does: a fixed backdrop (`rgba(0,0,0,.5)`, content 5vh from the top) holding a `role="dialog"` box with an 8px `control-accent` top border, sizes `small` 35% / `medium` 50% / `large` 1200px (full width under 600px), a title slot, an optional image slot, a body slot, and a round × button at the top right that is last in the Tab order. It locks page scroll, traps Tab in a list captured at open, closes on Escape, × and backdrop click, and fires no event. Its gaps are in [docs/upstream-issues/ilw-modal.md](../upstream-issues/ilw-modal.md).

## Decisions

- **`<dialog>` + `showModal()`.** The browser makes the rest of the page inert, puts the dialog in the top layer, closes it on Escape and fires `close`. The manual `inert` on `<body>`'s children goes away.
- **Buttons are a `<form method="dialog">`.** Each button's `value` is its index; `dialog.returnValue` says which one closed it, so the same markup closes without script on a server page. Escape, × and the backdrop leave `returnValue` empty: `dismiss`.
- **Classes, not a custom element:** `.ilw-modal` (+ `--small|medium|large|full`), `.ilw-modal-title`, `.ilw-modal-body`, `.ilw-modal-buttons`, `.ilw-modal-close`, in `src/styles/modal.css`. Usable from a server template with `showModal()` or invoker commands (`command="show-modal"`).
- **Fixes the upstream gaps:** `close` event; `autofocus` anywhere (focused explicitly, after insertion, for WebKit); clicks propagate; real `id`; Tab wraps over the focusables found at each keypress; `aria-describedby` only the message `<p>`, `aria-labelledby` the title.
- **Scroll lock in CSS:** `html:has(.ilw-modal:modal) { overflow: hidden }`, with `scrollbar-gutter: stable` so the page doesn't shift.
- **Kept:** the `openModal`/`alert`/`confirm` API, `CloseReason`, `returnFocusEl`, the `app-modal-N` ids, the `h2` title and `<p>` message.
- **Not carried over:** the image slot and `align="center"` (wait for C8 `ImageGallery`), `data-modal-target` triggers (use invoker commands).
- **Breaking:** the DOM contract. ta-manager's `ilw-modal[open]` selectors become `dialog.ilw-modal[open]` (or `role=dialog`), `.modal-buttons` becomes `.ilw-modal-buttons`. ta-manager follows in its own PR.
